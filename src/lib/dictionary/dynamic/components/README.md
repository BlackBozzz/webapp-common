# Компоненты динамических справочников

Здесь лежат универсальные строительные блоки, которые собираются по серверной схеме
`DynamicDictionarySchema`: таблица записей с серверной пагинацией, сортировкой и фильтрами
(`table/dictionary-record-table`), динамическая форма (`form/dictionary-dynamic-form`) и диалог
создания/редактирования записи (`dialog/dictionary-record-dialog`), который сам загружает свежий
DTO перед редактированием и раскладывает ошибки валидации backend по полям.

В `fields/` — поля формы по типам: текст, многострочный текст, число, дата, логическое значение,
перечисление, список, бинарные данные, а также выбор одной и нескольких записей связанного
справочника. Ссылочные поля загружают варианты и записи целевого справочника, поэтому пользователю нужен
грант `read` и на него. Страницы (`pages/`) только связывают эти компоненты с маршрутами и грантами.
