1. PostgreSQL и Flyway

Создайте БД, настройте spring.datasource.* и миграции. Таблицы @ArgentDataTable создаёт только приложение; схема БД не должна меняться из страницы документации.

2. Секреты

Храните JWT-ключи, пароль администратора, SMTP и пароль PostgreSQL в переменных окружения или secret manager. Не добавляйте секреты в репозиторий.

3. Безопасность

Проверьте роли и гранты, HTTPS, CORS, WebSocket origins и Swagger. По умолчанию пути Swagger публичны в SecurityAutoConfiguration: ограничьте их перед production.

4. Сборка и запуск

service-common: mvnw clean install, webapp-common: npm run build. Затем соберите main-backend и main-app.

5. Приёмочные проверки

Проверьте авторизацию, миграции, очереди, письма, QueryDSL, JasperReports и живые события. Отдельно проверьте /v3/api-docs и /api/argent-docs/roles.

6. Для разработчика

Полные инструкции по аннотациям, правам доступа, Swagger и каталогам находятся в DEVELOPER_GUIDE/backend/13_openapi_docs.md и frontend/09_documentation.md.
